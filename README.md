# Central de Demandas 📋

Seu gestor de demandas pessoal com IA integrada.

---

## Como publicar no Vercel (5 minutos)

### Passo 1 — Instale o Node.js
Baixe em: https://nodejs.org (versão LTS)

### Passo 2 — Suba o projeto no GitHub
1. Crie uma conta em https://github.com (se não tiver)
2. Clique em **New repository** → dê um nome → **Create**
3. Arraste a pasta `gestor-demandas` para dentro do repositório

### Passo 3 — Publique no Vercel
1. Acesse https://vercel.com e entre com sua conta GitHub
2. Clique em **Add New Project**
3. Selecione o repositório `gestor-demandas`
4. Clique em **Deploy** — pronto!

Você vai receber um link do tipo `gestor-demandas.vercel.app` para acessar de qualquer lugar.

---

## Como usar a IA

Na primeira vez que abrir o app:

1. Clique em **⚙ Configurar IA** no canto superior direito
2. Acesse https://console.anthropic.com e crie uma conta
3. Vá em **API Keys** → **Create Key**
4. Cole a chave no campo e salve

A chave fica salva só no seu navegador, ninguém mais tem acesso.

---

## Funcionalidades

- ✅ Adicionar demandas com título, descrição, prioridade, prazo e tags
- ✅ Filtrar por status (Nova, Em andamento, Bloqueada, Concluída)
- ✅ Busca por texto
- ✅ Assistente IA dentro de cada demanda
- ✅ Dados salvos no navegador (persistem entre sessões)
